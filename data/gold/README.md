# Gold layer (Power BI inputs)

Generated by `python run.py export` from `data/plein_tarif.duckdb`. CSV, UTF-8, comma separator,
'.' decimal separator, ISO dates. Keys: `date_key` (yyyymmdd), `fuel_key`, `station_key`.

| File | Grain | Rows |
|---|---|---|
| `dim_date.csv` | one row per day | 2,557 |
| `dim_fuel.csv` | one row per fuel | 6 |
| `dim_station.csv` | one row per station | 11,382 |
| `dim_market.csv` | day x fuel | 15,342 |
| `fact_national_daily.csv` | day x fuel | 15,342 |
| `fact_department_month.csv` | month x department x fuel | 47,924 |
| `fact_brand_category_month.csv` | month x brand category x road type x fuel | 4,029 |
| `fact_station_year.csv` | year x station x fuel | 240,470 |
| `dim_event.csv` | one row per event | 14 |
| `fact_rockets_feathers.csv` | sample x fuel x direction x horizon (weeks) | 72 |

Prices are in EUR per litre; `*_cts` columns in cents per litre. `price_ht_*` is the distributor price before
excise, VAT and the 2022 state discount (see docs/methodology.md). `n_*` columns allow Power BI measures to apply
the minimum-sample rule (10 stations, 30 days).
